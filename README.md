# Md. Naeem Hossen — Journalist Portfolio

## Quick customization
1. Open `index.html`.
2. Replace `YOUR_EMAIL@example.com` with your real email.
3. Replace the LinkedIn URL with your profile URL.
4. Add your published article/video links in the Work section.
5. Put your professional photo in this folder as `profile.jpg` and replace the portrait placeholder in `index.html` with:
   `<img src="profile.jpg" alt="Md. Naeem Hossen">`

## Free hosting
GitHub Pages can host static HTML/CSS/JS sites. Create a repository, upload these files, then enable Pages from Settings → Pages and choose the `main` branch and `/ (root)`. GitHub's official documentation explains the current steps.
